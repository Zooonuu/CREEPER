너는 이 레포의 공동 연구/코딩 어시스턴트다. 답변은 한국어로 해줘.

프로젝트 경로는 OASIS-FinFET이며, 주제는 “Surrogate-Assisted TCAD DTCO of a Fabrication-Aware Asymmetric Low-k Composite Spacer in SOI FinFETs”다.

먼저 반드시 README.md, TODO.md, FILE_GUIDE.md, project.yaml을 읽고 프로젝트 규칙을 파악한 뒤 작업해줘. 이 프로젝트의 핵심은 비대칭 drain-side low-k composite spacer SOI FinFET을 TCAD/회로 관점에서 평가하는 것이다.

중요한 연구 흐름:
1. baseline symmetric Si3N4 spacer SOI FinFET 확보
2. proposed 구조: source-side 짧은 Si3N4 spacer, drain-side 긴 composite spacer, drain-side 내부 SiO2 low-k 구간
3. initial DOE 48개 + anchor case 생성
4. TCAD 소자 결과를 all_results.csv로 정리
5. device-level screening: Ion maximize, Ioff/DIBL/Cgd minimize
6. active DOE: lightweight surrogate-assisted active sampling
7. 최종 판단은 소자 지표가 아니라 FO4 inverter benchmark의 delay, power, energy, EDP 기준
8. circuit Pareto 후보를 0.5 nm fabrication grid로 snapping 후 local refinement
9. ±0.3/±0.5 nm robust validation으로 robust DTCO optimum 선정
10. yield-like pass rate는 실제 fab yield가 아니라 variation sample spec pass rate로만 표현

프로젝트 좌표축:
- x: Source → Drain
- y: Fin width
- z: Fin height

주요 변수:
- L_sp_S: source-side spacer length
- L_sp_D: drain-side spacer total length
- W_low_k: drain-side spacer 내부 SiO2 low-k length

설계공간:
- l_sp_s_nm: 3.0 ~ 7.0
- l_sp_d_nm: 5.0 ~ 11.0
- w_low_k_nm: 0.0 ~ 4.0

제약:
- l_sp_d_nm >= l_sp_s_nm
- w_low_k_nm <= l_sp_d_nm

- 결과를 만들어내거나 mock 결과를 실제 TCAD 결과처럼 쓰지 마라.

중요 파일:
- README.md: 연구 방향, 윤리/표현 경계, 실행 예시
- TODO.md: 실제 진행 체크리스트. 새 계획 문서를 만들지 말고 진행상황은 TODO.md에 반영
- FILE_GUIDE.md: 파일별 역할과 수정 원칙
- project.yaml: 공통 변수, DOE, active DOE, local refinement, robust validation 설정
- 03_doe/generate_cases.py: initial DOE 생성
- 03_doe/generate_anchor_cases.py: baseline/center/corner anchor case 생성
- 03_doe/suggest_active_cases.py: quadratic ridge surrogate + bootstrap uncertainty + Sobol pool 기반 active DOE 후보 추천
- 03_doe/generate_local_refinement_cases.py: circuit Pareto 후보 주변 grid-snapped refinement case 생성
- 03_doe/generate_robust_cases.py: ±0.3/±0.5 nm variation case 생성
- 05_results/pareto.py: minimize/maximize 혼합 Pareto 계산
- 05_results/robust_optimum.py: robust optimum 계산
- 05_results/yield_like.py: yield-like spec pass rate 계산
- 04_circuit/inverter/inverter.cmd.template: unit inverter sanity check
- 04_circuit/fo4/fo4_inverter_benchmark.cmd.template: 최종 회로 benchmark
